# Two limits on the quantum reading: a keyed path is a local hidden variable, and the ring's single amplitudes have no even split

Depth **L1** (known math). Written 2026-11-12 for the advisory board, round 01 (objections Q-1, Q-2, M-2, Q-7), and
corrected the same day after round 02 (Q2-1, Q2-2, Q2-8, G2-8). Records:
`note/project/vibe/roadmap/board/round-0N/response.md` in the ClueSurf repo. Nothing here is a run.

## 1. A keyed path cannot violate CHSH in its own records

**Setting.** The base lists "Path: one measurement record, at every split one branch, chosen by a deterministic key"
(paper 0017, `01-the-base.tex`:41-42). The key is integer arithmetic on the beat, the dock and the slot
(`code/measure/full-key-paths.ts`:9-16, 60-69). The rule is local.

**Statement.** Let a path be computed from a start λ (the start state with the key table). Let Alice's setting a and
outcome A be read in a region R_A, and Bob's b and B in R_B, outside each other's light cones. If the distribution of
λ over the runs is independent of (a, b), and every run is counted, then the record frequencies satisfy
|E(a,b) + E(a,b') + E(a',b) − E(a',b')| ≤ 2.

**Proof.** On a path every split is decided by the key, so the path is a deterministic local map of λ. A is a function
of the path inside R_A's past light cone, which a change of Bob's setting cannot reach, so A = A(a, λ) = ±1, and
likewise B = B(b, λ). This is Bell's 1964 setting: for each λ, A(a)(B(b) + B(b')) + A(a')(B(b) − B(b')) is ±2.

**Scope.** Every run must be counted. Keeping only the runs with a clean definite outcome (11.8 percent in E-QTM-0144)
reopens the detection loophole, and then CHSH above 2 is possible without any nonlocality (objection Q2-8).

**Consequence.** Every CHSH value above 2 in the model comes from the amplitude state, never from a path's records
(E-QTM-0111, E-QTM-0138, E-QTM-0143 agree). A keyed path at the Born threshold is the dephased twin of the rule, which
misses interference (E-QTM-0157), so a path row is a result about that twin, not a sample of the amplitude present.

## 2. No single amplitude in the ring has squared size 1/2

**Statement.** No z in ℤ[ω][1/6], ω = e^{2πi/3}, has |z|² = 1/2, and the same holds in ℤ[ζ9][1/6].

**Proof.** Write z = x / (2^k 3^m) with x in ℤ[ω]. Then |z|² = N(x) / (4^k 9^m) with N(x) a nonnegative integer, and
|z|² = 1/2 needs N(x) = 2^{2k−1} 9^m, whose power of 2 is odd. But 2 is inert in ℤ[ω] (x² + x + 1 has no root mod 2),
so 2 divides N(x) only if 2 divides x, and then the power of 2 in N(x) is even. In ℤ[ζ9], |x|² is not an integer
(the field has degree 6), so the argument runs through valuations: 2 has order 6 mod 9, so it is inert and fixed by
complex conjugation, and v₂(x x̄) = 2 v₂(x) is even, while v₂(1/2) = −1 is odd (round 03, Q3-3).

**It fails with a golden ratio** (round 03, Q3-1). If the ring holds φ = (1 + √5)/2, as links in Σ(1080) would need,
then x = φ + ω has |x|² = φ² − φ + 1 = 2, so z = (φ + ω)/2 has |z|² = 1/2 exactly. The limit in this section holds only
with links in Σ(648).

**Scope (objection Q2-1).** This is about one amplitude. A branch weight is a sum of squared amplitudes, and
1/4 + 1/4 = 1/2: E-QTM-0131 reaches Schmidt weights (1/2, 1/2, 0) exactly in three swap-phase meetings. So
equal-weight branches exist, fine-graining is not limited to powers of 4, and the Hong-Ou-Mandel limit applies only
to a splitter that acts on the path mode alone. A splitter acting on path and role together is not covered.

## 3. Which group the links are, and which ring the amplitudes need

Σ(648), as a subgroup of SU(3), needs a ninth root of unity ε = ζ9² in its determinant-one diagonal generator
diag(ε, ε, εω) (`code/algebra/ninth-field.ts`:1-5, `test/experiment/quantum/links-are-the-clifford-group.ts`:541). What
lives in ℚ(ω) is another lift, generated by X, Z, the Fourier gate and diag(1, 1, ω), which is not in SU(3). Its
Fourier gate needs 1/√−3, and √−3 = 1 + 2ω has norm 3, so that lift lives in ℤ[ω][1/6]. Only 216 grid moves act
(E-QTM-0117), so the honest statement of a link is that projective image in U(3) with a named lift.

The lift matters. For a lone qutrit the ninth root is a global phase, but when a vibe crosses a link on one branch only,
the lift's scalar is a relative phase and changes interference. Two rows already use two lifts: E-QTM-0131 over
ℤ[ω][1/6] and E-FRC-0278 over ℚ(ζ9). The base must name one: ring ℤ[ζ9][1/6] with links in Σ(648), or ring ℤ[ω][1/6]
with the ℚ(ω) lift. The paper's ℤ[ω][1/2] (01:38-40) is wrong either way.

A ring-made CHSH value is never 2√2 under either lift: under the ℚ(ω) lift it is rational, and under the ℚ(ζ9) lift it
lies in ℚ(cos 2π/9), a cubic field with no √2 (round 03, Q3-4).
