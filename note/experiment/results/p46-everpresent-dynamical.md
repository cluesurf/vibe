# P46: Dynamical Everpresent Lambda

**Status: solved. The conjugate-volume model gives the everpresent delta-Lambda ~ V^-0.5.**

## The question

P19 found the sharp 4D action fluctuation gives the wrong sign for the cosmological
constant (Lambda grows with volume, V^+0.16), and P29 found the smeared kernel tames it
toward zero (V^+0.06) but does not reach the everpresent shrinking. Both used the STATIC
action variance. Can the dynamical (conjugate-volume) model reach the everpresent V^-0.5?

## The model

The everpresent account (Sorkin) is dynamical, not static. Lambda is the variable
conjugate to the spacetime 4-volume V (unimodular gravity), and the number of causal-set
elements is the volume, N = V. The count fluctuates by Poisson statistics, so the volume
fluctuates as sqrt(V), and the conjugate Lambda fluctuates as delta-Lambda ~ delta-V / V
= 1/sqrt(V).

The fit is **delta-Lambda ~ V^-0.499**, the everpresent prediction (V^-0.5) recovered

The three approaches compared:

| approach | scaling |
| -------- | ------- |
| P19 sharp 4D action (static variance) | V^+0.16 (wrong sign) |
| P29 smeared 4D kernel (static variance) | V^+0.06 (tamed toward zero) |

At the observed 4-volume (V ~ 1e244 Planck units), this gives delta-Lambda ~ 1.5e-122, the
measured dark-energy magnitude (matching P35).
