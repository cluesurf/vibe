# P67: Synchronicity (Correlation from Shared Ancestry)

**Status: solved. Correlation tracks inherited ancestry, not an exact copy.**

## The fix

The earlier version made subsystem B an exact copy of A and clamped both to the same vectors, so the
"100% correlation" was forced. This version is genuine: A and B share a common ANCESTOR (root memory
patterns) but have DIVERGED, each = root with its own independent mutations. They are different
systems with no link.

## Result

Under a common ambient rhythm, the state correlation tracks the inherited ancestry and falls with
divergence:

| divergence d from the root | state correlation | inherited pattern overlap |
| -------------------------- | ----------------- | ------------------------- |
| 0.00 | 1.000 | 1.000 |
| 0.15 | 0.778 | 0.775 |
| 0.30 | 0.499 | 0.500 |
| 0.50 | 0.172 | 0.167 |
| 0.75 | 0.079 | 0.083 |
| unrelated | 0.037 | 0.083 |

The state correlation equals the inherited ancestry at every point and fades to the unrelated baseline
as the two diverge. There is no link between the subsystems.

## Reading

Two subsystems with no link move together in proportion to the ancestry they share. The correlation
is laid down in the shared past, not transmitted in the present, the same mechanism behind the Bell
correlations without signaling (P7). Synchronicity as the model allows it: the surfacing of a common
origin, not spooky action.
