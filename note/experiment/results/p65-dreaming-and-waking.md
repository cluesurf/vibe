# P65: Dreaming and Waking (One Mesh, Two Regimes)

**Status: solved. Waking is pinned and veridical, dreaming roams the memory landscape.**

## The question

The roadmap asks for the same mesh in two regimes: coupled to shared external constraints
(waking) versus free internal exploration (dreaming).

## The model

A memory mesh stores several patterns as attractors (a signed Hebbian rule, ternary fills, so
each stored pattern is a stable state). The same mesh is then run two ways:

- **Waking**: an external input clamps part of the surface to a stimulus and holds it.
- **Dreaming**: no sustained clamp. A slow internal rhythm briefly cues one memory at the start
  of each window, then the mesh relaxes freely, and the rhythm cycles through the memories.

## Result

The mesh stores 4 patterns (memories), each a stable attractor.

- **Waking** (external clamp): the mesh settles on 1 distinct pattern, pinned to the one the
  world shows it, and the completion matches the input at 100 percent (veridical).
- **Dreaming** (no clamp, internal rhythm): in one continuous trajectory the mesh visits 4 of 4
  stored patterns, roaming its whole landscape.

## Reading

One mesh, one rule, one set of memories, two regimes. In waking, an external input clamps the
surface, and the mesh completes to the matching memory and holds it, veridical and stable,
anchored to the shared world. In dreaming, the clamp is gone, and a slow internal rhythm sweeps
the mesh through its own stored patterns, wandering the whole landscape, with free dynamics (and,
under softer cues, blends) in the transitions. The only difference is whether the shared external
constraint is imposed: pinned to reality when awake, free to roam its own depths when dreaming.

This is also why dreams are made of your own material, recombined. A dream is the mesh exploring
itself with the world let go, the same memories the waking mind is held against, now free to
recur and recombine.
