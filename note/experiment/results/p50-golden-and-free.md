## Implication 8: the golden ratio from independent directions

The golden ratio phi is computed three separate, independent ways:

| source | value |
| ------ | ----- |
| continued fraction x = 1 + 1/x | 1.61803399 |
| consecutive Fibonacci ratio | 1.61803399 |
| pentagon geometry, 2 cos(pi/5) | 1.61803399 |

All agree. It is the same constant the sunflower placement uses (P39), the Fibonacci
addressing uses (P42), and the modular central geodesic uses (P48). A constant arriving
from arithmetic, from a recurrence, and from geometry, all the same number, is a sign the
base is deeply ordered and elegant rather than arbitrary.

## Implication 7: order and freedom reconciled

On the perfectly ordered {7,3} crystal, the deterministic rule is:

- **reproducible** (the same start gives the same evolution): order.
- **computationally irreducible** (it evolves over many beats and is not the one-step
  response): free, must-be-lived.

So an ordered foundation still produces unpredictable, must-be-run behavior. You do not
have to choose between a lawful universe and a free one. The order is at the base, the
freedom is in the living-out, and an ordered base delivers both.
