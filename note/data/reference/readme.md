# Reference Data

The measuring stick. Every external number this package's experiments must match or use as a comparison: the Particle Data Group / Standard Model values, the fundamental constants, the mixing angles, and the geometric and group-theory targets the model derives. Structured (CSV and JSON) and documented (this folder).

The point: one place where the real numbers live, so any experiment claim ("we predict sin^2(theta_W) = 3/8") can be checked against the verified value at a glance.

## Provenance and verification

- **Every value carries a citation.** Each CSV row has a `source` column with a tag (for example `PDG-2024`, `CODATA-2022`, `NuFIT-6.0`, `Planck-2018`, `math:Hurwitz`, `phys:gut`, `vibe`). Each tag expands to a full citation, with authors, journal, year, and a link, in [sources.md](sources.md). The same map is embedded in [reference.json](reference.json).
- **Every empirical value was fetched from and reconciled against its primary source on 2026-06-24** (NIST/CODATA 2022, PDG 2024, NuFIT 6.0, Planck 2018). The `verified` column records that date. That pass corrected the constants from CODATA 2018 to 2022, several PDG masses, the CKM angles and Jarlskog invariant, and moved the neutrino sector from NuFIT 5.2 to 6.0. Corrections are noted inline and summarized in [sources.md](sources.md).
- Each value is tagged **measured** (empirical), **derived** (a geometric / group-theory target the model computes, or a known math / physics fact), or **defined** (an exact SI definition). A target the model **matches** is marked, a **mismatch** or **open** is marked honestly, with its energy scale where it matters (sin^2(theta_W) = 3/8 holds at unification, not at low energy).
- Values still drift each review and a few carry real tension (the W mass with the CDF-2022 outlier, the muon g-2, the Hubble constant). Re-run the verification when a new PDG, CODATA, or NuFIT release lands.

## The files

| file | what it holds |
|:--- |:--- |
| [constants.csv](constants.csv) | fundamental constants (c, h-bar, G, the fine-structure constant, the Fermi constant, the Higgs vev, Planck units, cosmology). |
| [particles.csv](particles.csv) | every Standard Model particle: mass, electric charge, spin, color, weak isospin. |
| [sm-parameters.csv](sm-parameters.csv) | the roughly 26 free parameters of the Standard Model, each tagged with its vibe origin status. |
| [mixing.csv](mixing.csv) | the CKM (quark) and PMNS (neutrino) mixing angles, phases, and the neutrino mass-squared splittings. |
| [theory-targets.csv](theory-targets.csv) | the geometric and group-theory numbers the model derives (ternary 3, the 24 of the cell, octonion 8, F4 order 1152, sin^2 theta_W = 3/8, Tsirelson, Born exponent), with whether the model matches. |
| [experiment-metrics.csv](experiment-metrics.csv) | the curated map of which experiment compares to which reference value, with target, tolerance, and intended status. |
| [reference.json](reference.json) | the same data as one machine-readable object, with the citation map embedded. |
| [sources.md](sources.md) | the bibliography: every `source` tag expanded to a full citation with a link, plus the verification change-log. |

## The cross-check (verification of the experiments)

The [verification/](verification/) subfolder holds the result of running the live experiment suite and checking each physics experiment against the reference values above. See [verification/readme.md](verification/readme.md). It is regenerated by running the suite and the cross-check, so it always reflects the current code, not a stale snapshot.

This folder is self-contained: the values live here, the experiments that consume them live in `../../../test/experiment/`, and the measures that compute the derived ones live in `../../../code/measure/`.
