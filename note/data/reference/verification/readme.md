# Verification

The cross-check: every experiment that compares to an external reference value, run live, with its measured number checked against the verified value in `../`. This is the double-and-triple-check rule (methodology section 0) applied to the reference data, not a trusted snapshot.

Generated by running the 27 comparison-bearing experiments and diffing their metrics against the reference CSVs. Regenerate with `pnpm call tmp/dump-physics.ts` then rebuild [cross-check.csv](cross-check.csv). The depth and live status come straight from the registry, so this never drifts from the code.

## How to read it

[cross-check.csv](cross-check.csv) has one row per experiment: its depth, its live status, the reference target, the reference value, the measured value, a verdict, and a note. The verdict vocabulary:

- **match** the measured number agrees with the verified reference value, and the experiment is sound (depth L1 or better, not circular).
- **partial** the experiment reproduces part of the target (an order of magnitude, a precondition), with the rest stated not derived. Honest.
- **open** the structure is forced but the identification with physics is unsettled.
- **match-circular** the number equals the reference, but the experiment hardcodes it (L0). The agreement is bookkeeping, not evidence.
- **enriched** the experiment gives a stronger or more exact value than the reference table recorded.
- **mapping-corrected** the experiment measures something different from what the curated map claimed. The map was wrong and is now fixed.
- **match-stale-input** the experiment's own hardcoded comparison value is slightly out of date versus the freshly verified reference. The derived number still matches.

## What the cross-check caught

The check earned its keep. It found four things a trusted snapshot would have missed:

1. **rg-unification was mismapped.** The curated map said it reproduces sin^2(theta_W) = 0.231 by running. It does not. It measures the **three-coupling unification gap**: the Standard Model misses unification by 5.61, the MSSM by 0.11. The sin^2(theta_W) running prediction lives in **weak-angle-prediction** instead (MSSM-run 0.2308 versus measured 0.2312). The map is corrected.

2. **gauge-group-from-octonions was mismapped.** The curated map said it yields SO(10) dimension 45. It actually yields the **Standard Model gauge group dimension 12** (su3 = 8, su2 = 3, u1 = 1, with G2 = 14 alongside). SO(10) = 45 is a different claim. The map is corrected.

3. **gr-gravitational-waves is L0 circular.** Its chirp exponent equals -3/8 to four digits, but the quadrupole waveform and the Peters decay law are hardcoded inputs. The number matching is bookkeeping, not a derivation. Flagged so it is never read as evidence.

4. **lorentz-bound-3434 is stronger than recorded.** The reference table noted a D4 anisotropy order of 4 (the numerical fit in lorentz-violation-scale). The exact deterministic moment identities cancel order 2 **and** order 4, leaving order **6**. The substrate's rotational isotropy is better than the table said.

Two experiments (flavor-mixing-pattern, and the observed Cabibbo angle generally) hardcode a pre-2024 comparison value (0.2245) that the 2026-06-24 verification updated to 0.22501. The derived prediction (0.217) is unaffected, but the experiment's own baseline could be refreshed.

## The honest bottom line

The genuine matches are the quantum bounds (CHSH, Tsirelson, Born exponent 2, Peres-Mermin 6 vs 4, Leggett-Garg 3/2), the geometric and group numbers (sin^2 theta_W = 3/8, F4 order 1152, the 24 directions, the octonion-to-triality chain, the warp factor 18.28, boundary dominance, the 3/4 perceived fraction), and the emergent-physics reproductions (Lorentz isotropy order, area law, 1/r potential, hyperbolic expansion). The weakest are the ones that hardcode their target (gravitational waves, L0) or only reach part of it (the mass hierarchy, ~3 of 5.5 decades). All of that is now stated, not buried.
