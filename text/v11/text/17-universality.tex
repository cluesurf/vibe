\section{Universality}

A computer is universal when it can imitate any other, so that whatever can be computed at all can be computed by it. The yardstick is the Turing machine, the simplest device that already captures every computation. Knit and mesh together clear the bar, and the proof was built four independent ways on the committed substrate. The two do different halves of the work, and it is worth keeping them apart. The knit supplies the logic, the gates and gliders and the counting moves, while the mesh supplies the wiring and the memory, the many-way junctions and the addressed tree a machine is laid out on. Neither computes alone. The knit without the mesh has no tape to write on, and the mesh without the knit is an inert lattice.

The first way is gates. The model's own rule on a line, a signed majority of its tones, is exactly a NAND, the single Boolean operation from which every circuit can be assembled, and from NAND one builds Rule 110, the elementary rule already proven universal on its own. The second is a railway. Margenstern's construction lays tracks and switches through a hyperbolic grid along which a token runs a program, and it ports straight onto the mesh \cite{margenstern2008}. The third is a register machine. The create and annihilate moves raise and lower a count, so a Minsky machine, increment, decrement, and a test for zero, runs on the charge, with addition and multiplication checked and the charge conserved throughout. The fourth is Conway's Game of Life, itself universal, run on the flat cubic cusp. Four roads, one destination.

\begin{result}[Turing-universal]
The knit run on the mesh is Turing-universal, shown four independent ways on the substrate, by NAND gates, by Margenstern's railway, by a Minsky register machine on the charge, and by Conway's Game of Life on the cusp. \cite{pollard2026vibetest}
\end{result}

Because the knit is reversible, the computer it builds is a reversible computer, the kind that need waste no energy while it runs, paying a cost only when a result is finally erased. That too was built, with Toffoli gates, on both the committed substrate and its three-dimensional cousin. So the substrate is not one machine but a medium in which any machine can be laid down.

Universality is the floor under everything that follows. Whatever the later parts need the mesh to hold, a memory, a self, a mind, the base is rich enough to hold it. The only question that ever remains is whether a structure emerges from the law on its own, never whether the mesh could represent it at all.
