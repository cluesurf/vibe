verdict or headline number moved. The others held every verdict boolean at all three sizes.

Five of the fourteen experiments converted in the last slice built their mesh with a depth that capped the size
before the chamber cap did, so their first scaled run held on an unchanged mesh. The audit's own check had a hole,
and the fix (a cap that reproduces the default mesh exactly, verified cell for cell, then scaled) is the reason the
table above can be trusted.
