\section{The Creation Stories in Native Terms}

Each creation story is retold here in its own vocabulary, with the tradition's names and terms restored. Each
is a direct parallel of the plain-English creation model given for that tradition in the body. The body
version shows the bare shape. This version shows the same shape in its traditional dress.
