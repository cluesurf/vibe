\section{The Arrow}

To have more than one distinction is to count them. Counting is discrete by nature, one then two then three, and the structure of all counting is the integers.

Time comes from order. Ask which of the number systems about to be built can be laid in a single line, totally ordered, compatibly with arithmetic. In any ordered ring every square is at least zero, because a positive times a positive is positive and a negative times a negative is positive. The integers pass this test and lie on the familiar line. But the moment the construction builds outward, a new element appears whose square is minus one, and since minus one is below zero, no order can place it. From that rung on, every richer system is unorderable, and stays so.

So the integers are the unique totally ordered rung. An order runs one way: that a is below b is not that b is below a. That one-wayness, the fact that the count has a before and an after and cannot be run backward, is the arrow of time. It is not added. It is the order of the counting, and it survives because the count stays orderable while everything it builds does not. There is a floor, the vacuum, the least value, and no ceiling, since the count climbs without bound, so the one available direction is one-way and outward from the seed. That is the shape of time, and it is derived, not assumed.

This same first loss, of order, is the first thing the doubling tower sheds in the next section, so the arrow of time and the structure that will become the octonions are two faces of one construction.
