\section{Base-Faithfulness Audit}

The discipline is simple. The model has only the base ingredients, and nothing may be quietly added. No
cohesion-bias, no maintenance term, no will, no gravity by hand, no repair. If a phenomenon does not emerge, the
correct move is to report the negative, not to bolt on an ingredient. This appendix audits every sector and
confirms that no test added anything to the base.

\subsection{The base}

\begin{enumerate}
  \item \textbf{The mesh}, the $\{3,4,3,4\}$ honeycomb. Its 24-direction coin, its cusp, and its boundary are
  properties of the one mesh, not separate ingredients.
  \item \textbf{The ternary tone}, $\{-1, 0, +1\}$ per cell.
  \item \textbf{The discrete beat}, the time step.
  \item \textbf{The one local rule}, stream plus collide, which is local, conserving, and reversible.
\end{enumerate}

\subsection{The caveats}

So the audit is real and not a rubber stamp, four caveats are recorded.

\begin{enumerate}
  \item \textbf{Continuous math is emergent tooling, not base.} Lie groups such as $\mathfrak{so}(8)$ and
  $\mathfrak{so}(10)$, Dirac operators, Green's functions, and Lie-algebra branchings are emergent and
  coarse-grained descriptions and analysis tools. They are never base ingredients. They describe what the discrete
  base flows to.
  \item \textbf{Some experiments used a simplified rule as a demonstrator.} The eternal-bootstrap mod-3 wave and
  the 2-component Dirac chain are examples. The conclusions transfer because the needed property was separately
  verified for the actual 24-direction rule, which was confirmed reversible and conserving by
  \texttt{run-gas-24dir} (p229).
  \item \textbf{The rule's exact collision is a specification, not a new ingredient.} Choosing the local collision
  specifies the single base rule. It does not add a second rule.
  \item \textbf{The recorded negatives were reported, not patched.} The pure rule churns with no selves (P101).
  Radial coarse-graining gives no tower (P187). The flat form-tower is a generic slow mode, not true nesting
  (P208). This is the discipline working.
\end{enumerate}

\begin{principle}[Nothing added to the base]
No test added anything to the base. Every result is a property of the mesh, the tone, the beat, or the one rule,
or an emergent consequence of them, with continuous mathematics used only as emergent-layer description, and the
recorded negatives reported rather than patched.
\end{principle}
